# Asset Provenance

[English](#english) · [简体中文](#简体中文)

## English

This file records the origin of visual assets shipped with Sona.

| Paths | Origin | Redistribution note |
| --- | --- | --- |
| `assets/backgrounds/` | Original images generated for Sona with OpenAI ImageGen, plus deterministic crops and color/layout derivatives made for desktop and player variants | Shipped as part of Sona under the repository license; prompts avoided logos, text, watermarks, and copied product UI |
| `assets/vinyl/` | Original ImageGen output created for Sona and locally processed for transparency | Shipped as part of Sona under the repository license |
| `assets/branding/sona_mark.png` | Original Sona mark supplied and designed by the project owner | Project branding; use of the source code license does not imply endorsement by the Sona project |
| `assets/branding/sona_mark_cutout.png` | Deterministic transparent-background derivative of the Sona mark | Same provenance as the source mark |
| Android launcher icons and Windows `.ico` files | Generated from the Sona mark | Same provenance as the source mark |
| `docs/site/assets/screenshots/` | Screens captured from Sona using demonstration data | Documentation use; screenshots must not contain private user data |
| `docs/site/assets/og-background.png` | Project-created website artwork | Shipped as part of Sona under the repository license |

No image in the built-in theme catalog was copied from a stock-photo website,
streaming service, album cover, or another application's interface. Reference
images were used only to discuss broad color, material, and layout principles;
the shipped images were generated or designed specifically for Sona.

OpenAI's Terms of Use state that, as between the user and OpenAI and to the
extent permitted by law, the user owns generated output. Contributors remain
responsible for ensuring that new inputs and assets do not violate third-party
rights: <https://openai.com/policies/terms-of-use/>.

## 简体中文

本文件记录 Sona 随程序分发的视觉素材来源。

| 路径 | 来源 | 再分发说明 |
| --- | --- | --- |
| `assets/backgrounds/` | 为 Sona 使用 OpenAI ImageGen 原创建成，并针对桌面/播放器执行确定性裁切、调色和构图派生 | 随 Sona 按仓库许可证分发；提示词明确避免品牌、文字、水印和复制现成产品 UI |
| `assets/vinyl/` | 为 Sona 生成的原创 ImageGen 输出，并在本地进行透明背景处理 | 随 Sona 按仓库许可证分发 |
| `assets/branding/sona_mark.png` | 项目所有者提供并设计的原创 Sona 标志 | 属于项目品牌；源码许可证不代表 Sona 对衍生产品进行背书 |
| `assets/branding/sona_mark_cutout.png` | Sona 标志的确定性透明背景派生文件 | 与原始标志来源相同 |
| Android 启动图标与 Windows `.ico` | 从 Sona 标志生成 | 与原始标志来源相同 |
| `docs/site/assets/screenshots/` | 使用演示数据从 Sona 截取 | 用于文档，截图不得包含用户隐私数据 |
| `docs/site/assets/og-background.png` | 项目自制网站素材 | 随 Sona 按仓库许可证分发 |

内置主题没有直接复制素材网站、流媒体平台、专辑封面或其他应用界面。参考图仅用于
讨论宽泛的颜色、材质和布局规律，最终分发图片均为 Sona 专门生成或设计。

OpenAI 使用条款说明，在法律允许的范围内，就用户与 OpenAI 之间而言，用户拥有
生成输出。贡献者仍需确保新输入与素材不侵犯第三方权利：
<https://openai.com/policies/terms-of-use/>。
