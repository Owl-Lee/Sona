# Sona Documentation / 文档索引

## English

This directory stores long-lived architecture, design, handoff, release, and
testing material so project knowledge is not limited to one workstation or
conversation.

| Directory | Contents |
| --- | --- |
| `architecture/` | Product positioning, technical architecture, and implementation highlights |
| `design/` | Interaction, motion, and visual guidelines |
| `handoff/` | Engineering handoff, current status, and known issues |
| `history/` | Earlier implementation logs and decision context |
| `releases/` | Release notes and release-engineering requirements |
| `testing/` | Performance and mobile-player test plans |

Historical documents preserve decisions from their original time. For current
paths, build commands, security requirements, and behavior, prefer the
repository root, `README.md`, and the current source code.

---

## 简体中文

这里保存项目的长期设计资料和交接信息，避免知识只留在桌面或一次性对话中。

| 目录 | 内容 |
| --- | --- |
| `architecture/` | 产品定位、技术架构、实现亮点与讲解材料 |
| `design/` | 交互、动效与视觉规范 |
| `handoff/` | 面向后续开发者的工程交接、当前状态与已知问题 |
| `history/` | 早期迭代技术日志，保留决策背景 |
| `releases/` | 发布说明与发布工程要求 |
| `testing/` | 性能与手机播放器测试计划 |

文档会保留历史事实，但凡涉及源码位置、构建输出和运行命令，应优先以仓库根目录、`README.md` 和当前代码为准。
